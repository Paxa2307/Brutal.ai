# Разбор видео «5 ошибок» (18.11–23.11.2026) и выводы для канала

Источник: ролик-реклама Telegram-канала автора научно-мотивационного TikTok (заявлено 10 000+ подписчиков).
Утверждения — маркетинговые, но все 5 пунктов совпадают с нашей статистикой.

| # | Ошибка по видео | Как было у нас | Вердикт |
|---|---|---|---|
| 1 | Начало с факта. Первая фраза должна бить лично по зрителю («вас не должно было существовать») | Хуки №1–3 были про «вас» | В целом ок, но ставки в хуке слабее: нужно «вы / ваша жизнь / ваше выживание» |
| 2 | История без разворота: факт-факт-факт → скролл. Нужно «на бумаге шансов ноль → СТОП → всё переворачивается» | №2 имел разворот («слабее, глупее — но мир ваш») → 2 527 просм.; №3 — список фактов без поворота → 275 просм. | **Главная причина провала №3** |
| 3 | Непроверенные цифры → в комментах обсуждают «враньё» | Фактчек делаем | Продолжаем |
| 4 | Музыка просто фоном. Перед разворотом музыка стихает → тишина → голос → «стоп» → дроп | У нас перед дропом был гул/райзер, полной тишины не было | **Внедрить полную тишину 1–2 с перед разворотом** |
| 5 | Банальный финал. Нужен конкретный образ + удар по зрителю, такой финал пересылают | №3 кончался призывом «напишите одним словом» | **Финал = образ из истории + удар; CTA — только в закреплённый комментарий** |

## Формула сценария v2

1. **Хук (0–2 с)** — удар лично по зрителю с высокими ставками. На экране — тот же текст крупно.
2. **«На бумаге» (≈3–15 с)** — почему у вас/вашего свойства «шансов ноль». Зритель должен почувствовать себя проигравшим.
3. **СТОП (1–2 с)** — музыка полностью исчезает, только голос: «Но…».
4. **ДРОП + разворот** — 2–3 доказательства, каждое сильнее предыдущего; «ваше секретное оружие».
5. **Финал** — конкретный образ из истории + прямой удар по зрителю. Одна-две фразы, которые хочется переслать. Без «пишите в комментариях» в озвучке.

## Технически

- `music.py`: новая секция `SILENCE` — музыка в ноль (остаётся только голос, максимум суб-удар сердца), затем оркестровый удар на первом слове разворота.
- Хронометраж 55–70 с.
