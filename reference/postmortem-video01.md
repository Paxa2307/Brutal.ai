Результат за 8 часов: ~400 просмотров, среднее время просмотра 9,6 с, досмотры 0,96 %.

## Выводы

1. Первые 3 секунды статичны — одна картинка вместо 6–8.
2. Интро без конкретики: зритель уходит ровно до первого факта (9,6 с).
3. Фрейм темы перевёрнут: канал-референс льстит зрителю («вы — венец эволюции»), мы его обвиняем.
4. Тема Милгрэма широко известна — нет эффекта «не знал».
5. Нет соперника-животного в кадре — главный визуальный крючок формата.
6. Ролик длиннее на 15–30 с, темп монтажа вдвое ниже.

## Правила для следующих роликов

- Хук: парадокс/абсолютное утверждение про «вас» + конкретный соперник в кадре с первой секунды.
- 6+ разных картинок за первые 3 с, ≥1,2 смены кадра в секунду на всём ролике.
- Первый факт — не позже 4 с; каждые 1–2 с новый факт или сравнение. Никаких «но есть одно но».
- Зритель — победитель. Тёмные темы подавать как «ваша суперсила», а не «ваш порок».
- 70–80 с, до 180 слов.
- Каждая картинка двигается: анимация, штампы НЕТ/LOSER/VICTOR, счётчики.
